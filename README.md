# choice-grid

Modern, high-performance daily habit tracker built with React, Vite, Tailwind CSS, and WCAG AA accessibility.

## Features
- **Micro-Interactions**: Fluid ease-out count-ups, scale animations, confetti particle bursts.
- **Accessibility**: 2D roving tabindex matrix navigation, screen reader announcements.
- **Mobile First**: Pull-to-refresh, vibration haptics, bottom navigation.
- **Offline & PWA**: Web app manifest, standalone mode.

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
